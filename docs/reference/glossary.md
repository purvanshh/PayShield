# Glossary

| Term | Definition |
|------|------------|
| **AUC-ROC** | Area Under the Receiver Operating Characteristic curve |
| **Agent** | Specialized service in the multi-agent system |
| **Celery** | Distributed task queue for async processing |
| **Confidence** | Model's certainty in its prediction (0-1) |
| **Decision Agent** | Final agent that synthesizes all analysis |
| **Ensemble** | Combination of multiple ML models |
| **Feature Engineering** | Transforming raw data into ML features |
| **Fusion Strategy** | Method for combining model outputs |
| **HPA** | Horizontal Pod Autoscaler |
| **Investigation** | LLM-driven deep analysis of suspicious transactions |
| **Kustomize** | Kubernetes configuration customization tool |
| **LLM** | Large Language Model |
| **Meta-Learner** | Model that learns to combine base model outputs |
| **PDB** | Pod Disruption Budget |
| **RPO** | Recovery Point Objective |
| **RTO** | Recovery Time Objective |
| **SealedSecret** | Encrypted Kubernetes Secret |
| **VPA** | Vertical Pod Autoscaler |
| **WebSocket** | Real-time bidirectional communication protocol |
