## Why It Improved

1. **Target-user readout + transaction self-attention** — replaced the global mean-pool readout, which diluted the scored user with neighbours, with direct extraction of the target user embedding and an attention-weighted sum over the target user's own transactions.
2. **Objective aligned to PR-AUC** — early stopping and checkpoint selection now monitor validation PR-AUC instead of ROC-AUC, so the saved checkpoint is the best fraud-finder, not the best ranker of the legitimate majority.
3. **Five new features** — merchant `is_shell` and `round_amount_share`; transaction `inter_arrival_gap`, `txn_count_5m`, `txn_count_1h` and `location_distance` make shell-merchant collusion, burst attacks and account takeover visible in the graph.
4. **Optuna hyperparameter search** over hidden size, layer count, dropout, pos_weight, learning rate and batch size, scored on validation PR-AUC.
