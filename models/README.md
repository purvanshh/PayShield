# Model Artifacts

This directory stores trained model artifacts, auto-generated model cards,
and fairness audit results.

## Contents

| Path | Description | Generated By |
|------|-------------|--------------|
| `gnn_benchmark_results.json` | GNN benchmark metrics (PR-AUC, AUC-ROC, latency, baseline) | `scripts/benchmark_gnn.py` |
| `payshield_gnn_v1_card.md` | Auto-generated model card (zero hand-edited metrics) | `scripts/generate_model_card.py` |
| `fairness_audit.py` | SPD/EOD on synthetic demographic slices | `python models/fairness_audit.py` |
| `production/calibrator_v1.pkl` | Fitted isotonic calibrator (ECE 0.010) | `engine/ensemble.py:ConfidenceCalibrator.fit()` |
| `registry/` | Versioned model artifacts (v1.0.0 statistical filter, v0.1.0 GNN) | `ml/registry.py` |

## Fallback Behavior

When no production model is available:

- **L1 (Statistical Filter)**: Runs rule-based velocity/geo/Benford checks (no model required)
- **L2 (GNN)**: Returns `MODEL_UNAVAILABLE` — ensemble falls back to L1-only fusion. No `type("L2",...)()` stub — real inference since Phase 3.
- **Ensemble**: Weighted fusion adapts to available layers; isotonic calibrator loaded if `calibrator_v1.pkl` exists
