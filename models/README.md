# Model Artifacts

This directory stores trained model artifacts generated by the `training/` pipeline.

## Contents

| Path | Description | Generated By |
|------|-------------|--------------|
| `calibration/` | Isotonic calibration models (`.pkl`) | `engine/ensemble.py:ConfidenceCalibrator` |
| `*.pkl` / `*.onnx` | Serialized model files | `ml/train.py` or `scripts/train_models.py` |

## Important Notes

- Model files (`.pkl`, `.onnx`, `.pt`) are **not committed to git** (see `.gitignore`).
- These artifacts are generated during training and should be deployed separately.
- For development, the system runs with fallback/default behavior when models are not present.
- Production models should be stored in a dedicated model registry (S3, GCS, or internal artifact store).
- Use `make train-models` (when available) or `python -m ml.train` to regenerate.

## Fallback Behavior

When no production model is available:
- `Layer1 (Statistical Filter)`: Runs rule-based velocity/geo/benford checks (no model required)
- `Layer2 (GNN)`: Returns default probability (0.0) — no graph model scoring
- `Ensemble`: Defaults to L1-only decision path
